# 示例

做得好的真实界面，用来看样子、学结构和行为。

现在都来自 Kotolog。它的配色、字体和圆角是它自己的选择，Kotolog 的文档也写明这些只是已有实现，不是未来设计必须遵循的要求，所以不要照抄到别的产品。

| 示例 | 学什么 |
|---|---|
| [条、卡、页、窗](kotolog-object-forms/README.md) | 一个对象在列表、卡、整页和窗口之间怎么切换 |
| [桌面工作台](kotolog-workbench/README.md) | 列表加详情栏的桌面布局，放不下时怎么让位 |
| [手机和宽窗](kotolog-mobile/README.md) | 同一套对象在手机和折叠屏内屏上的样子 |
| [命令行输出](kotolog-cli/README.md) | 同一个对象在终端里怎么表达 |

[content-stress.json](content-stress.json) 是检查界面用的压力内容：长标题、混排段落、难折行的字符串和极端数量。优先用产品的真实内容，它补充真实内容不容易碰到的情况。
