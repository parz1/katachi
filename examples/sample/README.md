# 样例页：今天的事项

- 来源：agent 按[交互规范](../../standards/interaction.md)写的，内容是示例数据，不连服务器
- 认可：用户还没看过。视觉有 3 个方向在比较，都没有定
- 阶段：交互原型

## 学什么

交互规范的默认做法都能在这里操作：

- 单击一行成卡，⌘Enter 成页，Esc 一次退一步。方向键换行，Delete 归档，⌘ 单击多选。
- 勾掉一项：圆圈和删除线马上出现，停一下再滑走，可以撤销。
- 在卡或页里改正文：未保存、保存中、已保存。勾上顶部的「保存会失败」，看失败时文字怎么保留、怎么重试。
- 「计划」是气泡，「更多」是菜单，「永久删除」是对话框。有未做完的子任务时，永久删除是禁用的，并写明原因。
- 「实验室例会」是只读的外部日程，用不到的控件都隐藏了。
- 记一笔：输入「明天交周报」，看识别结果；空着提交，看错误怎么显示。
- ⌘K 搜索；搜不到时的样子。
- 顶部的「状态」可以切到加载中、首次使用和读取失败；左边的「旅行」是筛选没有结果。

## 别学什么

- 颜色、字体和密度。下面 3 个方向都只是候选，选定之前不要照抄。
- 没有做窗、拖动、网址直达和终端。窗见[最小实现](../../patterns/object-forms/minimal.html)。

## 3 个方向

结构和行为完全相同，只有外观不同。比的时候点开一行、长成整页，再切窄屏和深色。可以拼接，比如 A 的标题配 B 的密度。

| | A 纸和卡片 | B 线和密度 | C 色块和留白 |
|---|---|---|---|
| 层次靠什么 | 卡片和阴影 | 分隔线和字重 | 底色和留白 |
| 字体 | 标题衬线，其余无衬线，正文 13 | 全部无衬线，正文 13，标题也小 | 全部无衬线，正文 15，标题很大 |
| 800 高的窗口放几行 | 8 | 14 | 5 |
| 颜色 | 暖底色，蓝色选中 | 没有色相，只有黑白灰，错误才用红 | 浅灰绿底，绿色选中 |
| 形状 | 中等圆角，圆形勾选框 | 小圆角，方形勾选框 | 大圆角，圆形勾选框 |
| 押注 | 每一项都有实体感，边界清楚 | 一屏看得多，扫读快，键盘为主 | 读着舒服，触屏好点，长标题不挤 |
| 牺牲 | 阴影、底色和边框占视觉，放得不多 | 偏冷，每一项的边界弱，触屏目标小 | 一屏放得最少，要多滚动 |

A 是 Kotolog 现在的外观：颜色、阴影和圆角从它的桌面原型实测，字号来自它的 `design-contract`。Kotolog 的原型用网络字体 Noto Serif SC，这里不加载网络字体，没有这个字体时退回系统的衬线字体。

## 验证

- 功能正确：通过。上面列的操作都在 Chromium 无头模式里走过，没有控制台错误。范围只有这个示例页，不连服务器。
- 视觉一致：只检查了没有坏。还没有选定的规范可以对照。3 个方向都看过 1280 的浅色和灰阶，并抽看了深色、整页和 390 窄屏；脚本确认 1440 到 320 都没有溢出，文字对比度和控件边界都过底线。
- 交互可用：部分通过。键盘走通了上面的流程，减少动效时直接切换，焦点照常移动。
- 未覆盖：读屏软件、Safari、Firefox、触屏真机，以及终端。
