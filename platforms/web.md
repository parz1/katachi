# web Web 浏览器

## 能力

- 单位：CSS px。
- 显示：宽度连续变化，用户可以缩放；字体可能加载失败；明暗模式和对比度偏好由用户决定。
- 输入：指针、键盘、触摸，可能同时存在。
- 场景：范围很广，由产品决定。

## 平台要求

- 所有操作都能用键盘完成；焦点顺序符合阅读和操作顺序。依据 WCAG 2.2 SC 2.1.1、2.4.3、2.4.7、2.4.11。
- 点击目标不低于 `constraint.target.web-min`。依据 WCAG 2.2 SC 2.5.8。
- 放大到 200% 时内容和功能不丢失；视口宽度为 `constraint.reflow.width` 时，不需要同时横向和纵向滚动；用户调大行高、字距和段距时内容不丢失。依据 WCAG 2.2 SC 1.4.4、1.4.10、1.4.12。

样式引用生成的 `tokens/build/tokens.css`，不复制数值。

## 必查

- 窗口尺寸：1440×900、1024×768、390×844，再加宽度为 `constraint.reflow.width` 的重排检查。
- 只用键盘走完主要流程。
- 放大到 200%；打开系统的减少动态；切换明暗模式（产品支持时）。
- 字体是否真的加载，中文回退字体是否符合预期。

## 验证

- 先用什么查：浏览器渲染和截图。
- 最终验证：目标浏览器。产品没写的话，在报告里写明实际查了哪些。
