# 平台

平台层：每个平台一个文件，写能力、平台要求、必查项和验证环境。通用的判断在 [foundations/](../foundations/README.md)，那里也写了两层怎么分。具体产品的选择在产品的 `DESIGN.md`。

这里的「平台」指一类运行环境，由显示能力、输入方式和使用场景决定，不等于操作系统。

| ID | 平台 | 文件 |
|---|---|---|
| web | Web 浏览器 | [web.md](web.md) |
| desktop | 桌面应用 | [desktop.md](desktop.md) |
| mobile | 手机 | [mobile.md](mobile.md) |
| adaptive | 折叠屏与自适应 | [adaptive.md](adaptive.md) |
| terminal | 终端 | [terminal.md](terminal.md) |

一个产品可以同时属于几个平台。比如手机应用要适配折叠屏，就同时看 `mobile.md` 和 `adaptive.md`。

首批验证的是响应式 Web（含手机和折叠屏宽度）和终端（`foundations/taste.md` 的 S-012），要看 `web.md`、`adaptive.md` 和 `terminal.md`。其他平台的文件先当检查清单，有真实产品时再使用。

> 这些文件目前只有事实和检查项，都还没有在真实界面上用过，也没有视觉规范。视觉判断校准后，再从真实界面提炼进来。

## 基线表格

每条通用基线在各平台上的做法写在哪里。这张表不代表已经验证。

| 规则 | web | desktop | mobile | adaptive | terminal |
|---|---|---|---|---|---|
| BASE-1 文字对比度 | 直接 | 直接 | 直接 | 直接 | 细化 |
| BASE-2 非文字对比度 | 直接 | 直接 | 直接 | 直接 | 细化 |
| BASE-3 不只靠颜色 | 直接 | 直接 | 直接 | 直接 | 细化 |
| BASE-4 操作方式和当前位置 | 细化 | 细化 | 细化 | 直接 | 细化 |
| BASE-5 目标尺寸 | 细化 | 细化 | 细化 | 细化 | 不适用 |
| BASE-6 缩放和重排 | 细化 | 细化 | 细化 | 细化 | 细化 |
| BASE-7 减少动态 | 直接 | 直接 | 直接 | 直接 | 细化 |
| BASE-8 内容不破坏界面 | 直接 | 直接 | 直接 | 细化 | 细化 |

- **直接**：按 [baseline.md](../foundations/baseline.md) 的原文执行。
- **细化**：目标不变，具体做法写在平台文件的「平台要求」里。
- **不适用**：这个平台没有对应的问题，原因写在平台文件的「平台要求」里。

校验脚本会检查这张表和平台文件是否一致。

按[应用面的标记](../foundations/README.md)，这些基线目前最多是「已映射」，还没有任何一条在真实界面上验证过。界面模式的应用面见 [patterns/README.md](../patterns/README.md)。

## 新增平台

1. 新建 `platforms/<id>.md`，格式如下。
2. 在上面的平台列表和基线表格里各加一项，在 `patterns/README.md` 的表格里加一列。
3. 运行 `node scripts/check.mjs`。

```markdown
# <id> <平台名>

## 能力

- 单位：
- 显示：
- 输入：
- 场景：

## 平台要求

（标准和平台规范的要求，以及基线表格里标为细化或不适用的规则。）

## 必查

（这个平台额外要检查什么。）

## 验证

- 先用什么查：
- 最终验证：
```

不要预先写视觉规范。没有人要求时，也不要主动添加手表、电视、车机、自助终端等平台。

## 暂缓的特殊场景

POS 这类由特定硬件和业务流程决定的界面，以后再考虑（`foundations/taste.md` 的 S-011）。已经查到的资料在 [later/pos.md](later/pos.md)，只作备忘，不算当前平台。

没有人要求时，不要为这些场景做设计。要启用时，把文件移回 `platforms/`，再按上面的步骤补齐表格和 tokens。

## 平台文件怎么长大

有真实产品时才增加这些内容：

- **语义映射**：通用层的角色和状态在这个平台上怎么表达。
- **平台专属模式**：只在这个平台上存在的做法。
- **平台 tokens**：见 [tokens/README.md](../tokens/README.md)。
