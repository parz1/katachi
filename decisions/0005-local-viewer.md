# 0005 用本地查看器直接看设计库，内容从仓库生成

- 状态：采用
- 日期：2026-11-06

## 背景

用户希望能直接看到设计库（`foundations/taste.md` 的 S-013），不只是读 Markdown 和 JSON。之前的最小版本把文档网站排除在外。

## 决定

- `viewer/` 是一个零依赖的本地页面，用 `node viewer/serve.mjs` 启动，每次打开都从仓库重新生成。
- 页面内容全部来自仓库文件，查看器里不写任何规范内容。
- 探索和示例会自动显示，可以切换窗口宽度和灰阶。之后比较方案都在这里看。
- 外观保持中性，并在页面上声明它不是设计规范。
- 只绑定本机地址，只读。
- `scripts/check.mjs` 检查账本、tokens 和平台都显示在页面上。

## 备选和放弃原因

- **Storybook 等现成工具**：要引入依赖和框架，也只适合 Web 组件，而现在还没有组件。
- **部署的文档网站**：要多一套发布流程，参考截图也不能公开。
- **把生成的页面提交到仓库**：每次改文档都要重新生成，容易过期。
- **手写展示页面**：和仓库内容不同步。

## 代价

- 多了一块要维护的代码，比校验脚本还长。它和设计资产分开放在 `viewer/`，以后不需要时可以整块删除。
- 只能在本机看，手机和其他人看不到。
- 终端在这里只能看示意，真实效果要到终端里看。

## 什么时候重新考虑

有组件需要交互调试，或者需要分享给别人时。
