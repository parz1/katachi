# 字体

- 状态：draft
- 来源：agent 起草的 3 个候选，用户还没选。没有参考任何现有产品

这是规范的第一步，还在比较，选定之前不能当规范用。

这一轮只比字体。字号、行高、颜色和布局 3 个方案完全一样，都是临时值，下一轮「排版」再定。标题字重取各字体里接近半粗的一档：A 和 B 是 600，C 没有 600，用 700。内容大多取自[内容压力测试集](content-stress.json)，有中文、英文、混排、数字和界面文字。

标题和正文可以分开选，比如 A 的正文配 C 的标题。

| | A 系统字体 | B 宋体标题 | C 文楷标题 |
|---|---|---|---|
| 标题 | 苹方 + SF | Noto Serif SC（思源宋体）+ Source Serif 4 | 霞鹜文楷 |
| 正文和界面 | 苹方 + SF | Noto Sans SC（思源黑体）+ Inter | Noto Sans SC（思源黑体）+ Inter |
| 押注 | 和系统融为一体，不用下载 | 标题和正文一眼分开，像认真排过的文档 | 有手写的温度，一眼能认出来 |
| 牺牲 | 没有自己的面貌，要靠排版和颜色建立 | 要下载字体；宋体的细笔画在小字号容易发虚，所以只用在标题 | 要下载字体；不够正式；英文和数字也是手写感 |
| 这一页下载 | 0 | 1.4 MB | 1.3 MB |
| 中文标点 | 连续标点挤压；省略号靠下（用了 SF 的字形） | 正文挤压，标题的「》（」「）。」不挤；标题的省略号靠下、破折号断开（用了 Source Serif 的字形） | 正文挤压，标题不挤；省略号和破折号正常 |
| 跨平台 | 每个系统用自己的字体，看起来不一样 | 各平台一致，原生应用要把字体打包进去 | 同 B |
| 授权 | 系统自带，不能分发 | SIL OFL 1.1，可以打包 | SIL OFL 1.1，可以打包 |

省略号和破折号的问题来自字体顺序：英文字体排在前面，这两个符号就用了它的字形。这不是字体本身的问题，下一轮排版要解决。

A 在 Windows 上换成微软雅黑和 Segoe UI，在安卓和 Linux 上换成思源黑体和 Roboto。B 和 C 的中文字体按字切片，网页只下载用到的部分；一个字重的全部切片约 3–5 MB（实测 Noto Sans SC 3.4 MB，文楷 4.4 MB），原生应用要打包完整字体，安装包至少大这么多。终端的字体由用户的终端决定，不在这一轮里。

比较页从 Google Fonts 和 jsDelivr 加载字体，没加载到时页面上会写明。选定后再决定怎么托管。3 个方案只在 macOS 的 Chromium 上渲染过，A 在 Windows 和安卓上的样子没有看过。
