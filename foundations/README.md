## 规则格式

重要规则尽量包含下面每一项。缺示例就写明「待补」，不要省略。

```markdown
### <编号> <一句话规则>

- 状态：standard / draft / adopted / validated
- 适用：什么情境下用；什么情境下不用
- 做法：具体数值或行为（数值写 token 名，不复制数值）
- 示例：链接到 examples/ 或截图
- 理由：为什么这样做
- 例外：什么时候可以不遵守
- 依据：taste.md 条目，或标准条款
```

## 规则状态

| 状态 | 条件 |
|---|---|
| standard | 来自外部标准或平台规范，不是审美选择 |
| draft | 在一次探索或页面中用过，还没得到用户认可 |
| adopted | 用户认可，并用在至少 1 个认可的示例里 |
| validated | 在第二个页面或第二个产品中复用，没有修改，或修改后又验证过 |

## Web 和原生共享什么

初始假设，要等第一个原生产品检验后再确认（见 `taste.md` 的 O-009）。

| 共享：含义相同，实现可以不同 | 按平台决定 |
|---|---|
| 色彩语义和对比度下限 | 导航结构、返回方式、手势 |
| 间距比例和字号层级的角色 | 具体字体和渲染方式 |
| 动效的意图，以及减少动态的要求 | 动效的实现和系统默认曲线 |
| 内容规则和交互状态的要求 | 控件外观、焦点表现、系统字号的适配方式 |
